# Chamber Discord bot

Chamber is bot for daily checking for only "Commit issues Chamber" discord server

## Technical Requirements

- Node.js
- npm/yarn
- Create bot for project. Visit: [discord.com/developers/applications](https://discord.com/developers/applications) and follow the directions

## Get started

### Configure .env

Rename `.env-example` to `.env`

TOKEN = Discord bot token<br/>
CLIENT_ID = Discord bot client ID<br/>
GUILD_ID = Discord server ID (need to enabled developer mode)<br/>

### Run

```
yarn
yarn deploy-commands
yarn dev
```

### How to use

After invite bot to Discord server you can use next commands:

- /checkin [yesterday][today]
- /leaderboard
